# AI YT Studio — обновления программы для Windows

Служебный репозиторий: отсюда программа AI YT Studio сама скачивает новые версии.

- `latest.json` — описание последней версии, подписанное ключом разработчика. Программа проверяет подпись и контрольную сумму и не установит подменённый файл.
- `releases/<версия>/` — установщик, разрезанный на части меньше 100 МБ (ограничение GitHub). Программа скачивает части, склеивает и проверяет SHA-256.

Без ключа лицензии установщик не работает. Купить или продлить ключ: https://t.me/aiytstudio
